# Changelog

## 1.1.1

* **Автообновление.** В `ModConfig.json` и `ModConfig.en.json` прописаны `ProjectUrl` и
  `PluginData.GitHubRelease` — лоадер Reloaded-II теперь сам предлагает обновления из релизов
  этого репозитория, настройки (`Config.json`) при обновлении сохраняются.
* **Постоянные имена архивов.** Релизные файлы теперь называются без номера версии
  (`P5R.SocialStatMultiplier_RU.zip`, `..._EN.zip`, `..._RU_EN.zip`) — иначе автообновление
  искало бы файл со старым номером и ломалось на каждом следующем релизе.
* **Отдельные архивы под язык + маркер `RELOADED`.** Для автообновления и установки в один
  клик с GameBanana пакер делает одиночные архивы (по одному моду внутри) и кладёт в их
  корень пустой файл `RELOADED`.
* **README переорганизованы:** один язык — одна страница (`README.md` — английский,
  `README_RU.md` — русский), добавлены разделы «Какую версию ставить», «Автообновление»,
  «Скриншоты» и «Если что-то не работает».
* `pack_release.py` проверяет настройки автообновления и совпадение имени файла с именем
  архива; релиз по тегу больше не перезатирает текст релиза автосгенерированными заметками.

## 1.1.0

* Двуязычная сборка: русская и английская версии мода собираются из одного кода
  (`dotnet build -c Release` и `dotnet build -c Release -p:ModLang=EN`);
  отличаются только тексты — название мода в лоадере, подписи настроек, лог и иконка
  (`Strings.cs`, `ModConfig.en.json`, `Preview.en.png`).
* Релизный архив теперь содержит обе версии в подписанных папках
  (`RU_Русская_версия`, `EN_English_version`) и общий исходный код.
* Добавлены `build.sh`, автотесты в CI и автоматическая сборка релиза по тегу.

## 1.0.1

* Исправлена ошибка загрузки мода: `Failed to Load Reloaded-II: Object reference not set to an
  instance of an object` в `Startup.CanSuspend()`. Загрузчик обращается к `CanSuspend()` и
  `CanUnload()` из конструктора `ModInstance` — то есть **до** вызова `StartEx()`, поэтому все
  обращения к объекту мода сделаны null-безопасными.
* Папка настроек создаётся принудительно (иначе `FileSystemWatcher` внутри шаблона падал бы на
  несуществующей папке).
* `Config.json` создаётся сразу при первом запуске игры с модом — его можно править блокнотом.
* В автотесты добавлены регрессионные сценарии на вызовы загрузчика до старта мода.

## 1.0.0

* Первый выпуск: множитель 1…10, включение/выключение на ходу, поиск массива социальных очков по
  сигнатуре, слежение за приростом раз в 20 мс, защита от переполнения 16-битных значений и от
  ложных скачков при загрузке сейва.
