# Скриншоты для страницы мода

В `README.md` и `README_RU.md` уже есть раздел «Скриншоты»: сейчас там показывается только
иконка мода, а четыре картинки ниже — закомментированы. Когда снимешь их, положи файлы сюда
**с точно такими именами** и убери в README комментарии `<!-- ... -->`.

| Файл | Что снять | Как это сделать |
|---|---|---|
| `01-launcher-settings.png` | список модов в Reloaded-II с включённым «Social Stat Multiplier» / «Множитель социальных очков» и открытой панелью настроек | запустить лоадер, нажать шестерёнку рядом с модом |
| `02-multiplier.png` | крупно поле **Multiplier** / «Множитель» со значением (например, 2) | тот же экран настроек, обрезать до поля |
| `03-in-game.png` | момент начисления очков в игре: всплывающая плашка вида «Обаяние ↑» / «Charm up» | сделать скриншот (Win+Shift+S) в момент получения очков |
| `04-log.png` | строка лога лоадера о найденной сигнатуре и/или о начислении | включить `VerboseLog: true`, получить очки, скопировать строку из лога |

Требования: PNG, ширина 800–1600 px, вес до ~500 КБ на файл, без личных данных в кадре
(ник в лоадере, пути к папкам — можно замазать). Скриншоты в игре — только из лицензионного
геймплея, без артов и логотипов Atlus/Sega крупным планом.

Если скриншотов нет и делать их не хочется — просто удали закомментированный блок из README
и этот файл: страница будет работать и без картинок.
