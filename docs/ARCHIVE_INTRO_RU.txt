АРХИВ: МНОЖИТЕЛЬ СОЦИАЛЬНЫХ ОЧКОВ для Persona 5 Royal (мод для Reloaded-II)
===========================================================================

Внутри ДВЕ версии мода — функционально они абсолютно одинаковые, отличаются только
языком надписей (название мода в лоадере, подписи в настройках, сообщения в логе):

    RU_Русская_версия\    — русская версия   (в лоадере называется «Множитель социальных очков»)
    EN_English_version\   — английская версия (в лоадере называется «Social Stat Multiplier»)

Ставить нужно ЛЮБУЮ ОДНУ из них.

Как ставить (коротко):
  1) распаковать архив;
  2) открыть выбранную папку (RU_Русская_версия или EN_English_version);
  3) папку P5R.SocialStatMultiplier из её подпапки Mods скопировать в
     <папка Reloaded-II>\Mods\;
  4) включить мод в списке лоадера и запустить игру.

Подробная инструкция (установка, настройка множителя, включение/выключение на ходу,
что именно умножается, ограничения и решение проблем) лежит ВНУТРИ выбранной папки:

    RU_Русская_версия\ЧИТАЙ_МЕНЯ.txt      — по-русски
    EN_English_version\README.md          — на английском

Как менять множитель: шестерёнка «Configure» рядом с модом в лоадере, либо файл
<Reloaded-II>\User\ModConfigs\P5R.SocialStatMultiplier\Config.json

    {
      "Enabled": true,
      "Multiplier": 2,
      "VerboseLog": false
    }

Значения применяются на ходу, перезапуск игры не нужен.

Если ставишь одиночный архив (P5R.SocialStatMultiplier_RU.zip) — лоадер сам предложит
обновления мода; можно и вручную скачать свежий архив и заменить папку мода.
Настройки при обновлении сохраняются.

Нужен мод-библиотека Reloaded.Memory.SigScan.ReloadedII (идёт в комплекте с Reloaded-II).
Файлы игры не изменяются: мод только умножает значения в памяти и в любой момент
выключается обратно.

Исходный код (общий для обеих версий, C#, .NET 7) — в папке «Исходники» внутри архива
и в репозитории на GitHub. Язык сборки выбирается параметром:

    dotnet build -c Release                  (русская версия)
    dotnet build -c Release -p:ModLang=EN    (английская версия)
